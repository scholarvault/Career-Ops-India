Also free and already wired: 30 employer sources — 27 ATS boards (Lever, Greenhouse, Ashby, SmartRecruiters) plus the Tesla, EPAM and Amazon career portals, and Workday when enabled with CAREER_OPS_WORKDAY=1 — and Naukri through your own Chrome profile. No key is needed for any of them.

Free keys — optional

LinkedIn has no public jobs API, and scraping it breaks their terms. These aggregators already hold a licence to redistribute the listings — including LinkedIn-sourced ones — so a key here is the legal way to widen coverage. All three are free; each stays dormant until you paste a key.

Sign in once

Auto apply drives the same Chrome profile you sign in with here. Sign in to each portal once; the cookie stays on this machine and no password is stored. If a run meets an OTP, a captcha or a login wall, it pauses and asks you in the browser panel.

NaukriSign in with Google or your Naukri account.
Indeed IndiaSign in with Google. Indeed keeps its own profile.
LinkedInOpened and prefilled only; auto apply never submits here.

After signing in, open the browser panel to confirm the session. Every job on that site reuses it.

Remembered forms

When the filler has read a site's application form once, it keeps the field list so the next application on that site skips the discovery pass. Nothing here is an answer — only the shape of the form. Delete a row to make it look again.

MCP server

This install ships its own MCP server. Point Claude Desktop, Cursor or any MCP client at it and the agent can search Indian postings, score a CV and build an application plan.

ServerWhat it givesState

The server speaks JSON-RPC over stdio and never writes anything except protocol messages to stdout. It uses the same discovery and scoring code as this page, so a tool call and a page load cannot disagree.
