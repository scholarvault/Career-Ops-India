Where we look

How “your session” works No password is ever typed into this app.
  1. Press Connect Naukri. A real Chrome opens inside Career-Ops — not a separate window — at naukri.com. It runs on this machine, not on a server.
  2. Sign in there yourself — password, Google, or the OTP Naukri sends. This app never sees the password and never stores it.
  3. We keep only the session folder at data/browser-profile. That is what lets the next search run as you without asking again.
  4. Discovery reads the public search pages and stores the posting, its date and the link. Nothing is submitted.
  5. On a posting, Apply opens the real form. We fill what your profile already answers; you press submit. Many Naukri apply buttons hand off to the company's own ATS (Lever, Greenhouse, Workday) — those we can fill directly.

Naukri has no “sign in with Career-Ops” button and no permission screen to grant. There is no third-party OAuth. The only honest route is the one above: you sign in on Naukri's own page, in your own browser. If Naukri shows a bot check, the window waits for you — we never solve it.
