Job hunting already takes enough work.

The same details, entered again on every portal. The same resume, uploaded under a new filename. The work is real. The repetition is not.

Applying for a job in India means keeping several searches alive at once: a Naukri profile, an Indeed alert, a company careers page, a WhatsApp forward that needs checking before it expires. Each one asks for expected CTC, notice period, experience and a resume, in its own form.

Career Ops India was built to make that process organised and inspectable. Software that carries the work of a job search should be accessible, and the people using it should be able to see how it works.

That is why it is open source. Not as a marketing line, but because a tool that reads your CV and drives a browser should be readable itself.

Five steps, each one visible in the interface. Status labels say what is finished and what is still being built.

STAGE / 01 LIVE

Discover

Live

Naukri and Indeed India through your own browser session, 27 employer ATS boards, and company portals including Tesla, EPAM and Amazon.

Score

Live

A deterministic 100-point match across role, skills, experience, industry, location, ownership and compensation, with the strongest and weakest dimension named.

Prepare

Live

Resume tailoring that keeps every role and date, and an ATS keyword gap report that runs without a model. Tailoring needs your own AI key.

Apply

Partial

The form is filled from an answer bank you control: CTC, notice period, work authorisation, links. Auto apply submits it and records the confirmation; the manual path still leaves submit to you.

Track

Live

Every application writes to a local audit log, with a daily cap and a duplicate check before the next one starts.

It is not a blind auto-apply bot. It automates where a platform permits it, and assists where it does not.

One repository. Every branch readable.

Three commands to a working workspace.

It is a local application, not a hosted service. That is the point: the data and the browser session stay on your machine.

  1. 1

    Clone the repository

    git clone https://github.com/scholarvault/Career-Ops-India.git
cd Career-Ops-India
  2. 2

    Install and start

    pnpm install
pnpm start
  3. 3

    Open the workspace

    The app runs at localhost:4173. Sign in to Naukri in the browser panel once; the session is reused.

Before you start

  • Node 22 or newer and pnpm.
  • Chrome or Edge for the browser-backed sources.
  • A Naukri account if you want Naukri discovery. The password is never stored.
  • An AI key only for resume tailoring. Discovery, scoring and the ATS gap report run without one.

Windows, macOS and Linux. The setup is developer-oriented today.
