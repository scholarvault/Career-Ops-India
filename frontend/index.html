Job hunting already takes enough work.

The same details, entered again on every portal. The same resume, uploaded under a new filename. The work is real. The repetition is not.

Applying for a job in India means keeping several searches alive at once: a Naukri profile, an Indeed alert, a company careers page, a WhatsApp forward that needs checking before it expires. Each one asks for expected CTC, notice period, experience and a resume, in its own form.

Career Ops India was built to make that process organised and inspectable. Software that carries the work of a job search should be accessible, and the people using it should be able to see how it works.

That is why it is open source. Not as a marketing line, but because a tool that reads your CV and drives a browser should be readable itself.

STAGE / 01 LIVE

Discover

Live

Naukri and Indeed India through your own browser session, 27 employer ATS boards, and company portals including Tesla, EPAM and Amazon.

Score

Live

A deterministic 100-point match across role, skills, experience, industry, location, ownership and compensation, with the strongest and weakest dimension named.

Prepare

Live

Resume tailoring that keeps every role and date, and an ATS keyword gap report that runs without a model. Tailoring needs your own AI key.

Apply

Partial

The form is filled from an answer bank you control: CTC, notice period, work authorisation, links. Auto apply submits it and records the confirmation; the manual path still leaves submit to you.

Track

Live

Every application writes to a local audit log, with a daily cap and a duplicate check before the next one starts.

It is not a blind auto-apply bot. It automates where a platform permits it, and assists where it does not.

One repository. Every branch readable.

Three commands to a working workspace.

It is a local application, not a hosted service. That is the point: the data and the browser session stay on your machine.

  1. 1

    Clone the repository

    git clone https://github.com/scholarvault/Career-Ops-India.git
cd Career-Ops-India
  2. 2

    Install and start

    pnpm install
pnpm start
  3. 3

    Open the workspace

    The app runs at localhost:4173. Sign in to Naukri in the browser panel once; the session is reused.

Before you start

  • Node 22 or newer and pnpm.
  • Chrome or Edge for the browser-backed sources.
  • A Naukri account if you want Naukri discovery. The password is never stored.
  • An AI key only for resume tailoring. Discovery, scoring and the ATS gap report run without one.

Windows, macOS and Linux. The setup is developer-oriented today.

Bring your own agent

You already have Claude. Paste one prompt and it builds this for you.

No terminal knowledge needed. Copy the prompt, paste it as your first message in Claude Code, Codex, Kimi, Cursor, Gemini, Copilot, Hermes, n8n — any agent that can run commands. It checks your machine, clones the repo, starts the app, and walks you through your first search.

setup prompt
You are setting up Career Ops India on my computer. It is a free, open-source, local-first job-search workspace (AGPL-3.0). It runs on my machine; nothing is hosted. GOAL Get it running at http://localhost:4173 and walk me through my first job search. RULES - Ask before installing anything system-wide. Use what is already installed when you can. - Never ask for my passwords, and never type them. - Never submit a job application without my explicit yes for that specific job. - If a step fails, show me the exact error, try one alternative, then stop and ask. STEP 1 - CHECK MY MACHINE Run these and report the versions: node --version pnpm --version git --version I need Node 22 or newer. If pnpm is missing: npm install -g pnpm If Node is older than 22, tell me how to update it for my OS and wait for me. STEP 2 - GET THE CODE git clone https://github.com/scholarvault/Career-Ops-India.git cd Career-Ops-India STEP 3 - INSTALL AND START pnpm install pnpm start The app serves http://localhost:4173. Confirm it responds before you continue. If the port is busy: pnpm stop STEP 4 - OPEN IT Open http://localhost:4173/console.html in my browser. STEP 5 - MY FIRST RUN, ONE STEP AT A TIME Wait for me at each step. 1. Ask me to upload my resume (PDF or DOCX) and confirm the role I am targeting. 2. Show the market counts for my role and my city. 3. Recommend 10 jobs and explain the top 3 scores in one line each. 4. Tailor a resume for the job I pick. This needs an AI key; if I do not have one, tell me where to paste it in Settings. 5. Fill one application form. Stop before submit and show me exactly what it filled. OPTIONAL The repo ships an MCP server (pnpm mcp) with tools for search, scoring, shortlisting, tailoring and applying. If you support MCP, offer to connect it. WHEN DONE Tell me the local URL, what is running, and the single next thing I should do. Keep it short.

Paste it as your first message. The agent asks before it installs anything, and never submits an application without your yes.
